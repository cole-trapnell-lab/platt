# `plot_gene_expr`

**Deprecated.** Use [`plot_gene_expression()`](plot_gene_expression) instead.

```r
plot_gene_expr(...)
```

## Details

`plot_gene_expr()` is now just a thin, deprecated shim that forwards all arguments (`...`) to [`plot_gene_expression()`](plot_gene_expression). It is kept only for backwards compatibility with older scripts and tutorials — new code should call `plot_gene_expression()` directly, which documents the full, current set of arguments.
